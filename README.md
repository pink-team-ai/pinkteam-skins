# 핑크팀 회의실 스킨

회의실 기능은 그대로 두고, 겉모습만 바꾸는 CSS 스킨 모음입니다.
어떤 채팅·회의실 웹앱에도 붙일 수 있는 가벼운 스킨입니다.

## 스킨 목록

| 파일 | 스킨 | 느낌 |
|---|---|---|
| `kakaotalk-skin.css` | 카카오톡 스타일 | 깔끔하고 대중적. 노란 말풍선 + 하늘색 배경 |
| `cyworld-skin-v3.css` | 싸이월드 v3 | 진짜 미니홈피 감각. 하늘 + 노란 격자 + 파란 탭 |
| `cyworld-skin-v2.css` | 싸이월드 v2 | 깔끔한 분홍 미니홈피 |
| `cyworld-skin.css` | 싸이월드 v1 | 색·폰트만 바꾼 가벼운 버전 |

## 붙이는 방법

1. 원하는 스킨 CSS 파일 하나를 `index.html`과 같은 폴더에 넣습니다.
2. `index.html`의 `<head>` 안에서, 기존 `<style>` 블록 **뒤**에 아래 한 줄을 넣습니다.
   (순서가 중요합니다. 스킨이 나중에 와야 원래 색을 덮어씁니다.)

   ```html
   <link rel="stylesheet" href="kakaotalk-skin.css">
   ```

3. `<html>` 태그에 `data-skin` 속성을 넣습니다.

   ```html
   <html lang="ko" data-skin="sky">
   ```

## 색 바꾸기

`data-skin` 값만 바꾸면 됩니다.

**카카오톡 스킨**
- `sky` = 카톡 기본 하늘색 (기본)
- `pink` = 연핑크
- `mint` = 민트
- `gray` = 회색
- `dark` = 다크

**싸이월드 스킨 (v3 기준)**
- `classic` = 진짜 싸이월드 (기본)
- `pink` = 핑크핑크
- `soda` = 하늘소다
- `mint` = 민트초코

## 빼는 방법 (롤백)

`<link rel="stylesheet" href="...">` 한 줄과 `data-skin` 속성만 지우면
원래 테마로 돌아갑니다. 파일 삭제까지 할 필요는 없습니다.

## 주의

- 이 스킨에는 API 키·비밀번호·토큰이 없습니다. 넣지도 마세요.
- 카카오톡·싸이월드 상표와 로고는 사용하지 않았습니다. 색과 형태만 참고했습니다.
- JS·HTML·기능은 건드리지 않습니다. CSS만으로 바꿉니다.
